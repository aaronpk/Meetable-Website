A minimal events website for your community

Meetable is an open source, self-hosted home for your events. Publish your meetups, conferences and online sessions. People can subscribe to your calendar, RSVP, and share what happened.

Get started View on GitHub

Your events, on your own site

Meetable gives a community or organization one place to list upcoming events and keep an archive of past ones. Each event gets its own page with everything attendees need to know. Afterward, the page collects the photos, blog posts and notes people share about it.

Run it just for yourself or open it up to your whole team. It's built on Laravel, and you can host it anywhere PHP runs.

Features

  • Event discovery

    Upcoming events on the home page, an archive of past events, and day, month and year views.

  • Rich event pages

    A cover photo, location, website and ticket links, and a Markdown description. Mark events as tentative, postponed or cancelled, and add a video recording after the event.

  • Recurring events

    Set up an event as a template and Meetable creates the upcoming dates for you. It supports weekly, biweekly and monthly schedules, including patterns like "the second Tuesday".

  • Tags

    Give each event one or more tags. Visitors can browse by topic, and every tag has its own page and archive.

  • Calendar feeds

    iCal feeds for the whole site, for each tag and for each event. An "Add to Calendar" link exports an .ics file or opens Google Calendar.

  • Timezone aware

    The timezone is set automatically from the event's location. A built-in converter shows visitors the start time in their own timezone.

  • RSVPs

    Logged-in users can RSVP yes, no, maybe or remote, and everyone can see who's coming.

  • Photos & responses

    Upload photos with alt text. With Webmention, people can post photos, blog posts and notes from their own websites, and you approve them in a moderation queue.

  • IndieWeb friendly

    Event pages are marked up with h-event microformats. You can also import an event from another site just by pasting its URL.

  • Flexible login

    Log in with a passkey, GitHub, OpenID Connect, Vouch Proxy or Heroku. Use it for a single organizer or for many users with admin permissions.

  • Integrations

    Schedule Zoom meetings automatically, and post notifications to Discord. AI assistants can find your events through the built-in MCP server, and other tools can add events through the API.

  • Make it yours

    Set your own logo, favicon, site text, custom CSS and analytics, all from the settings page.

Get started

Meetable needs PHP and MySQL. Pick whichever setup suits you, and see the README for full instructions.

Docker Compose

Download the config files, fill in .env, and start the containers.

curl -O https://raw.githubusercontent.com/aaronpk/Meetable/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/aaronpk/Meetable/main/.env.example
docker compose up -d

Docker instructions

Manual install

Install it on your own server with PHP 8.2+, Composer and MySQL or MariaDB. Redis is optional.

git clone https://github.com/aaronpk/Meetable.git
cd Meetable
composer install
php artisan migrate
